You change the product by describing what you want. The agent works on its own branch, shows you screenshots, and opens a pull request. An engineer reviews and merges it. You cannot break anything by trying.

<Note>
Examples use Claude Code on the web. In Codex, start with `$` instead of `/`.
</Note>

## Where to work

| You have | Do this |
|---|---|
| Nothing installed | Open [claude.ai/code](https://claude.ai/code) or [chatgpt.com/codex](https://chatgpt.com/codex), or the Claude or ChatGPT phone app. Pick the repository. [Full steps](/how-to/use-the-kit-from-the-browser) |
| No agent open at all | Fill in the **Request a change** issue form on GitHub, if the repository has one |
| The kit on your own computer | [Install the kit](/how-to/install), then work the same way |

Start every session with `/start-here` if you are unsure. It checks the repository is ready and picks the right skill for what you say.

## What to type

### Explore before you decide

```text
/faker-mode try three layouts for the empty cart screen. show me a screenshot of each side by side.
```

The agent builds each version behind a switch, takes screenshots, and puts them side by side. The versions are throwaway. Pick one, or ask for a mix: "the second layout with the first one's illustration". Then the agent builds the chosen one properly.

### Match a design exactly

```text
/faker-mode make the settings screen match this mockup exactly. <paste the image or a link>
```

The agent compares screenshots of the app with your mockup until they match, and shows you both.

### Ship a visual change

```text
/request-a-change the primary buttons should use 12px corner radius everywhere
```

What happens:

<Steps>
  <Step title="The agent restates your request">
    It asks "Is that right?" Answer in plain words.
  </Step>
  <Step title="It builds the change on a branch">
    Never on the live product.
  </Step>
  <Step title="It shows before and after screenshots">
    In the conversation and on the pull request. For a web app you may also get a preview link.
  </Step>
  <Step title="It opens a pull request">
    It describes in plain words what changes for users. An engineer reviews and merges it. You get a comment if a decision is needed.
  </Step>
</Steps>

In Codex, press the button on the finished task to open the pull request yourself.

### Report something that looks wrong

```text
/request-a-change the checkout total overlaps the pay button on small phones
```

Say what you see and where. The agent reproduces it, fixes it, and shows screenshot proof.

### Understand how the UI works

| You want | Type |
|---|---|
| How something works today | `/how is the theme applied to every screen?` |
| Why it was built that way | `/why do we use a custom date picker?` |
| An explanation of a change the agent made | `/teach` |
| The last answer in plainer words | `/bro` |

### Make feedback stick

When you keep giving the same design feedback ("use the spacing tokens, not raw numbers"), add it to STYLE.md or ask an engineer to run `/correct` on it. The goal is a check that catches it automatically, so you never have to say it again. [Why this works](/explanation/trust-ladder).

### Learn

```text
/create-learning-path I want to read pull requests with confidence
```

Later, `/run-learning-retrospective` checks your progress and adjusts the plan.

## What you will not be able to do alone

The agent stops and hands over to an engineer when a request touches money, permissions, personal data, or deleting things. That is on purpose.

## If something does not work

| You see | What it means | Who fixes it |
|---|---|---|
| The agent does not know `/start-here` | The kit does not load in this cloud environment | An engineer, with `/setup-cloud-agents` |
| Test results but no screenshots | The repository has no verification skill, or the app cannot run in the cloud | An engineer, with `/create-verification-skill` |
| A mobile app with no simulator | Cloud machines cannot run an iPhone simulator | The agent tells you what you get instead: screen-test screenshots, build-system screenshots, or a test build for your phone |
| The agent cannot open a pull request | Your GitHub connection lacks access to the repository | Reconnect GitHub, or ask a repository admin |
| No pull request after a Codex task | In Codex, you open it | Press the button on the task |
