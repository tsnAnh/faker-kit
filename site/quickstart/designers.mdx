You describe what you want in plain words. The agent builds it on a separate branch, shows you screenshots, and opens a pull request for an engineer to review. Nothing goes live without that review, so you cannot break anything by trying.

## Before you start

<Steps>
  <Step title="Open the agent">
    You do not need to install anything. Open [claude.ai/code](https://claude.ai/code) or [chatgpt.com/codex](https://chatgpt.com/codex), or either phone app, and pick the repository. [Step-by-step instructions](/how-to/use-the-kit-from-the-browser).
  </Step>
  <Step title="Say hello">
    Type `/start-here` (`$start-here` in Codex). It checks the repository is ready and asks what you want to do.
  </Step>
  <Step title="Check you will get screenshots">
    Screenshots need the repository's verification skill. `/start-here` checks this for you. Without it you only get test results; ask an engineer to run `/create-verification-skill`.
  </Step>
</Steps>

<Note>
Mobile apps: a cloud machine cannot run an iPhone simulator. The agent tells you up front what you get instead, usually screenshots from automated screen tests, from the team's build system, or a test build on your phone.
</Note>

## Your first three tasks

<AccordionGroup>
  <Accordion title="Try three versions and pick one" icon="table-columns" defaultOpen>
    ```text
    /faker-mode try three layouts for the empty cart screen. show me a screenshot of each side by side.
    ```
    The versions are throwaway. Pick one, or ask for a mix: "the second layout with the first one's illustration". The agent then builds the chosen one properly.
  </Accordion>
  <Accordion title="Make a screen match your design" icon="object-group">
    ```text
    /faker-mode make the settings screen match this mockup exactly. <paste the image or a link>
    ```
    The agent compares screenshots of the app with your mockup until they match, and shows you both.
  </Accordion>
  <Accordion title="Ship a small change" icon="paper-plane">
    ```text
    /request-a-change the primary buttons should use 12px corner radius everywhere
    ```
    The agent restates your request and asks "Is that right?", builds it, takes before and after screenshots, and opens a pull request. You get the link.
  </Accordion>
</AccordionGroup>
