# Weekly review

A schedule started this run. No one is watching, so finish without asking questions.

1. Follow the `/weekly-review` skill for the last 7 days of the default branch, with one change: include non-merge commits from every author, not only the current git user.
2. Post the recap as a new issue titled "Weekly review" with today's date, written for the whole team, including non-engineers.
3. If there were no commits, post nothing and end by saying so.
