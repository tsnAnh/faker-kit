# team-kit

A trust-ladder team kit for Claude Code, Codex, and Pi. It vendors the Cursor team's agent plugins (pstack, cursor-team-kit, thermos, and more) and adds `trust-ladder`, which routes every correction you give an agent to the layer that can hold it: codebase, static analysis, rules and review bots, skills, or the style guide.

Usage instructions are in progress under `docs/`.
